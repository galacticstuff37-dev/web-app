# HOMEGROWN

Кликабельный прототип веб-аппа для контейнерного огорода (US-рынок).
Grow real food where you already live.

## Что где

| Файл | Что это |
|---|---|
| `index.html` | Мобильный веб — то, что открывается на телефоне. Десктоп-адаптива пока нет |
| `flow.html` | Пользовательский флоу: что видит человек, что делает система, куда ведёт |
| `review.html` | Тот же прототип в рамке телефона + индекс экранов, для просмотра с ноутбука |
| `proto.py` | Генератор. Все три файла собираются отсюда — правки вносить только сюда |
| `manifest.webmanifest`, `sw.js` | PWA: установка на домашний экран и офлайн |
| `img/` | Фотографии (Unsplash License) и иконки приложения. Нужны в рантайме |
| `fonts/` | Caprasimo и Inter Tight локально. Нужны в рантайме |
| `icons-solid/` | Phosphor Icons fill, MIT. В рантайме не нужны — инлайнятся при сборке |

## Сборка

```bash
python3 proto.py
```

## Что работает в прототипе

Онбординг проходится целиком, план собирается из реальных ответов, растения
добавляются и удаляются с отменой, задачи отмечаются и двигают прогресс,
поиск ищет по 21 культуре, пэйволл переключает тариф.

Палитра и типографика сняты с кейса Hers, все цвета проверены на WCAG AA,
отступы и размеры подчинены сетке 4/8 px, тап-зоны не меньше 44 px.

## Полный экран без адресной строки

В обычной вкладке браузера адресную строку скрыть нельзя — это ограничение самого
браузера. Приложение сделано устанавливаемым: открой ссылку на телефоне и добавь
на домашний экран (iOS: Поделиться → «На экран Домой»; Android: подсказка появится
сама). После этого оно запускается без адресной строки и тулбара, работает офлайн.
