# HOMEGROWN

Кликабельный прототип веб-аппа для контейнерного огорода (US-рынок).
Grow real food where you already live.

## Что где

| Файл | Что это |
|---|---|
| `index.html` | Мобильный веб — то, что открывается на телефоне. Десктоп-адаптива пока нет |
| `flow.html` | Пользовательский флоу: что видит человек, что делает система, куда ведёт |
| `review.html` | Тот же прототип в рамке телефона + индекс экранов, для просмотра с ноутбука |
| `proto.py` | Генератор. Все три файла собираются отсюда — правки вносить только сюда |
| `manifest.webmanifest`, `sw.js` | PWA: установка на домашний экран и офлайн |
| `img/` | Фотографии (Unsplash License) и иконки приложения. Нужны в рантайме |
| `fonts/` | Caprasimo и Inter Tight локально. Нужны в рантайме |
| `icons-solid/` | Phosphor Icons fill, MIT. В рантайме не нужны — инлайнятся при сборке |
| `app/` | Порт на React (Vite + TypeScript): исходники |
| `react/` | Собранный React-порт. Лежит в репозитории, потому что Pages раздаёт статику |
| `supabase/` | Схема базы (миграции), письма входа и инструкция по проекту |
| `tools/stands/` | Проверочные стенды: гоняют сборку в настоящем Safari и печатают отчёт |

## Сборка

```bash
python3 proto.py          # прототип: index.html, review.html, flow.html
cd app && npm install && npm run build   # React-порт в ../react/
```

## Порт на React

Прототип на `proto.py` остаётся живым и не тронут — React собирается в
отдельную папку и доступен по `/react/`.

Перенесены **все 29 экранов**. Механическое — скриптом дословно: дизайн-система
(CSS, токены и контрасты не переписывались руками), 28 иконок, справочник 29
видов, 4 ZIP. Логика — вручную: модель сезона, модель ухода, движок плана,
библиотека, настройки.

Маршрут `/react/#review` — замена `review.html`: те же экраны в рамке телефона,
индекс, переключатели состояний данных и iframe с прототипом рядом для сверки.

Порт сверяется с оригиналом ЧИСЛАМИ, а не на глаз:

```js
window.__audit()                       // модель сезона: окна, monthMap, сортировка, кэш
window.__stats(window.__state().plants) // health score, задачи недели, careStats
window.__syncAudit()                   // слияние с базой: все сценарии, без аккаунта
window.__sync()                        // один проход синхронизации, отдаёт отчёт
```

Первые два должны давать то же, что `careStats()` / `weekTasks()` и ручные
проверки окон в прототипе. `__syncAudit()` — `ALL SYNC CHECKS PASS`.

## Синхронизация между устройствами

Приложение **local-first**: `localStorage` — источник мгновенности, все экраны
рисуются без сети, Postgres — вторая копия и способ довезти изменения до другого
устройства. Ни одного состояния «загружается» на экранах нет и не появится.

Кто прав при расхождении, решает **снимок последней отправки** рядом с
состоянием (`hg.sync`): ключ строки → отпечаток её полей. Отпечаток не совпал —
меняли здесь, выигрывает локальное; ключ был в снимке, а строки нет — здесь
удалили, в базе ставим `deleted_at`; ключа нет ни там, ни там — строка приехала
с другого устройства, берём её. Подробно — в шапке `app/src/lib/sync.ts`.

Синхронизация запускается по трём поводам: изменилось синхронизируемое (с
задержкой), вкладку снова открыли, появился аккаунт. Таймера нет.

Вошедший человек видит **экран Account** (из настроек): в какой аккаунт вошёл,
как именно и что из его данных уже на сервере — цифры из снимка отправки, поэтому
ни спиннера, ни отказа. Sign out и Delete account живут там же. Экрана входа для
вошедшего больше нет: при заходе он получает приветственный лист, один раз за
визит (визит — вкладка, флаг в `sessionStorage`).

Кадры с камеры (`data:`-URL) пока остаются только локальными: им нужен Storage.

## Что работает в прототипе

Онбординг проходится целиком, план собирается из реальных ответов, растения
добавляются и удаляются с отменой, задачи отмечаются и двигают прогресс,
поиск ищет по 21 культуре, пэйволл переключает тариф.

Палитра и типографика сняты с кейса Hers, все цвета проверены на WCAG AA,
отступы и размеры подчинены сетке 4/8 px, тап-зоны не меньше 44 px.

## Полный экран без адресной строки

В обычной вкладке браузера адресную строку скрыть нельзя — это ограничение самого
браузера. Приложение сделано устанавливаемым: открой ссылку на телефоне и добавь
на домашний экран (iOS: Поделиться → «На экран Домой»; Android: подсказка появится
сама). После этого оно запускается без адресной строки и тулбара, работает офлайн.
